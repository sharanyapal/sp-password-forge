# Password Forge

Cryptographically secure password generator with adjustable entropy and strength guidance.

**Live application:** https://sp-password-forge.vercel.app  
**Technology:** HTML, CSS, JavaScript  
**Visual direction:** Neo-brutalist password workshop  
**Source:** https://github.com/sharanyapal/sp-password-forge

## Implemented functionality

- Web Crypto cryptographic randomness
- Customizable length and character groups
- Entropy estimate and one-click clipboard

## Run locally

```bash
python -m http.server 8000
# Open http://localhost:8000
```

No build step or account required.

## Project structure

- `index.html` — semantic interactive application page
- `style.css` — independent responsive art direction and components
- `app.js` — application logic and input handling
- `app-base.js` — local browser utilities

## Safety and scope

A working portfolio-scale app, not a production security service. Local-only browser computation unless otherwise explained. No credentials are included.
